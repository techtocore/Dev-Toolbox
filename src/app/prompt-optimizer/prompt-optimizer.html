Prompt Engineering Best Practices
Do's
  • Be Specific: Use concrete details and clear instructions
  • Provide Context: Explain the background and purpose
  • Define the Role: Specify who the AI should act as
  • Set Boundaries: Use constraints like "do not" or "must"
  • Use Examples: Show desired input/output pairs (few-shot)
  • Specify Format: Define how the output should be structured
  • Break It Down: Use sections, numbered lists, or headers
Don'ts
  • Avoid Vagueness: Don't use "this", "that", "it" without clarity
  • Skip Filler Words: Remove unnecessary politeness
  • Don't Assume: Don't expect the AI to guess context
  • Avoid Ambiguity: Be explicit about what you want
  • Don't Overload: Split complex tasks into multiple prompts
  • Minimize Jargon: Use clear language unless technical terms are needed
