Usage Guide
Why use JSON schemas with LLMs?
  • Structured Output: Ensure LLMs return data in a consistent, parseable format
  • Data Extraction: Extract specific fields from unstructured text
  • Function Calling: Define parameters for LLM function/tool calls
  • Validation: Constrain LLM responses to valid data types and values
Provider-specific formats
Claude tool_use

Anthropic's Messages API. Schema goes inside tools[].input_schema; force selection with tool_choice: { type: "tool", name }. Works with all Claude 4.x models.

OpenAI tools

Modern Chat Completions tool calling — supersedes the deprecated functions/function_call fields. Add strict: true for guaranteed schema conformance.

OpenAI Structured Outputs

Use response_format: { type: "json_schema", strict: true } when you only want JSON back (no tool dispatch). Every property must be in required; the tool auto-fills this for you.

Gemini responseSchema

Pass responseMimeType: "application/json" + responseSchema in generationConfig. Supports Gemini 2.5+ and Gemini 3.

Raw JSON Schema

Universal Draft-2020-12 schema. Embed via <schema> tags in any prompt, or feed to OSS validators (Ajv, jsonschema).
